About the Project

What is ShinyDex?

ShinyDex is an interactive Pokédex dedicated to the original 151 Pokémon and their shiny forms. It uses live Pokémon data to create a searchable and responsive frontend experience.

Built with HTML, CSS, JavaScript, and PokéAPI.
